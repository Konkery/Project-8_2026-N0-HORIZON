## 5. КРАТКИЕ КОММЕНТАРИИ ПО ПУНКТАМ РЕЕСТРА

- **П. 2** — закрытие начинается с этапа постоплаты N1/N2; до этого момента
  реестр остаётся пустым, это норма стартового периода.
- **N1 (п. 3)** — накопительное закрытие: итоговый пакет формируется по мере
  приёмки комплектов КД, а не одним актом в конце срока.
- **N3 (п. 3)** — по позиции У.2 действует позиция исполнителя: результат —
  полнофункциональный прототип; формулировки актов должны соответствовать
  протоколу разногласий (rev.02 v02), а не первоначальному тексту.
- **Требования к оформлению** — согласуются со стороной заказчика до первого
  акта (риск отказа в подписании из-за формулировок).
- **Сверки взаиморасчётов** — проводятся при переходе этапов оплаты, хранятся
  в документационном контуре, в этот реестр попадают только подписанные акты.

## 6. ПОРЯДОК ВЕДЕНИЯ

1. Регистрируется и **выставление**, и **подписание** каждого закрывающего
   документа (две даты, сторона, объём).
2. Указывается закрываемый объём (позиция / этап / экземпляр) и остаток по заказу.
3. Расхождения по формулировкам акта — строка реестра корректировок старта.
4. Подписанные экземпляры — в `09__Подписанные документы\`, скан-копии — здесь.

## 4. КРАТКИЕ КОММЕНТАРИИ ПО ПУНКТАМ РЕЕСТРА

- **N1** — самый ранний по фактическому старту: вводное совещание 22.10.2026,
  исходный шкаф передаётся по форме М15; в У.4 акцептованной Спецификации № 1
  указана модель `Knowhy G80` при предмете `Knowhy N96` — опечатка в реестре
  корректировок, уточнение направлено письмом Исх. № M2.
- **N2** — методика «анализ → ТЗ → адаптация ПТК → финальный прогон» является
  эталонной для N3 и перспективного N5; план-график ведётся в ИРП заказа.
- **N3** — крупнейший заказ портфеля (80 % стоимости); состав утверждён
  Решением №2; подписание приостановлено исполнителем по У.1/У.2 — статус
  отслеживается в реестре заказов N3.
- **N4–N7** — границы объёмов вынесены из N1–N3 сознательно (см. отчёт о
  переговорах, раздел 7); инициация — по триггерам выполнения.
- **Глобальные показатели** — пересчитываются при каждой перегенерации типа 40
  из мастера `20__work_spec`; в реестр заносятся фактические суммы, без округлений.

## 5. ПОРЯДОК ВЕДЕНИЯ

1. Новый заказ группы заводится строкой в разделах 2–3 в день получения заказа
   или решения об инициации.
2. Статус контрактования — по фактическому событию ЭДО (акцепт / подписание /
   приостановка) с датой.
3. Сводные показатели обновляются после каждой корректировки мастера тип 20 и
   перегенерации типов 30/40.
4. Подробные хронологии в рамке не дублируются — ссылка на реестр заказа.

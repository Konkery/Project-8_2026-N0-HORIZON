## 2. ЭВОЛЮЦИЯ ПРОДУКТОВ (2023 → 2026)

### 2.1. 2023 · платформа «Horizon Automation»

Универсальная платформа автоматизации с двумя связанными ветвями:

| Ветвь | Суть |
| :--- | :--- |
| **Horizon Automation PLC** | промышленные PLC-контроллеры под управлением фирменного одноимённого фреймворка |
| **Horizon Automation Server** | промышленные хабы на базе промышленных микрокомпьютеров под управлением фирменного фреймворка |

### 2.2. 2025 · OEM-проект с ООО «Точные машины» (ТМ)

Решение идти по R&D-схеме с собственным продуктом: разработка вендинговой платформы
с управлением на российской `Horizon Automation`, база — вендинговые шкафы компании
**Knowhy**. Результат — программно-технический комплекс **ПТК `Horizon VM {тип-модели} rev.01`**
(ревизия 1 = группа ПТК на конструктиве и базовых актуаторах/сенсорах Knowhy).

ПТК — система АСУ ТП с тремя уровнями управления:

| Уровень | Обозначение | Функция |
| :--- | :---: | :--- |
| Нижний | АСУ НУ | полевой уровень: управление исполнительными механизмами, сбор данных сенсоров |
| Средний | АСУ СУ | серверный слой: СУБД, логирование, брокеры сообщений |
| Верхний | АСУ ВУ | HMI-компоненты, взаимодействие пользователя с системой (UI) |

### 2.3. Решение о собственной линейке «Horizon VM»

Своя ветвь промышленных вендинговых аппаратов под фирменным именем **Horizon VM**.
Конструктивная база (производитель шкафов) на тот момент не выбрана. Первый этап:
база — поставщик готовых шкафов (с комплектом низовых актуаторов/сенсоров или без);
текущие усилия: разработка ПТК и ПО АСУ, отбор поставщика шкафа, сопряжение АСУ.

### 2.4. 2026 · три решения заказчика (ТМ)

| № | Решение | Значение для нас |
| :---: | :--- | :--- |
| 1 | Отказ от Knowhy по вендинговому направлению (финансовые условия, качество шкафов) | линия OEM на Knowhy завершается |
| 2 | Новый поставщик комплектующих — **Wate technology** | развитие линейки для заказчика — на базе Wate |
| 3 | Создание аффилированного лица **ООО «ТМ Технология» (ТМТ)** — вывод вендингового бизнеса из ТМ | ТМТ — надлежащий контрагент по рамке и всем заказам N1–N7 |

## 4. ЗАКАЗ N1 · КОНСТРУКТОРСКАЯ ДОКУМЕНТАЦИЯ KNOWHY N96/MASTER

**Предмет:** разработка комплекта КД по доработке металлоконструкции шкафа
`Knowhy N96/master` для размещения ПТК `Horizon VM Hybrid M96/50`.
**Результат:** комплект КД для изготовления. **Состав:** 8 позиций.

Узлы, разрабатываемые в заказе:

| № | Узел |
| :---: | :--- |
| 1 | Модуль размещения электронных компонентов ПТК |
| 2 | Узел коммутации сети ~230 В (автоматический выключатель по ПУЭ, заземляющий контакт, вынос в зону доступности персонала) |
| 3 | Интегрированный узел крепления LCD-дисплея, хаба АСУ ВУ, RFID/QR-считывателей (замена крепления моноблока, ниша двери №2) |
| 4 | Эскизы общего вида изделия |
| 5 | Транспортировочная тара и защита критичных компонентов |
| 6 | Внешний бокс размещения HMI-компонентов (LCD, RFID, QR, хаб ВУ) |
| 7 | Оценка переноса точек крепления колёс (увеличение межосевого расстояния; отчёт с оценкой технологии, стоимости и сроков) |
| 8 | Кронштейн для камер видеонаблюдения |

**Не включено в N1:** изготовление металлоконструкций, сборка/монтаж, поставка и
логистика шкафов, эксплуатационная документация — это отдельный перспективный
заказ (N4) и объединённый N5.

## 5. ЗАКАЗ N2 · ПТК HORIZON VM ДЛЯ KNOWHY G80/MASTER

**Предмет:** реверс-инжиниринг постаматного аппарата `Knowhy G80/master` и адаптация
ПТК `Horizon VM Post M80 rev.01`. **Результат:** полнофункциональный укомплектованный
ПТК для управления изделием. Работы (сжато):

| № | Работы |
| :---: | :--- |
| 1 | Инженерный анализ (реверс-инжиниринг) существующей конструкции изделия |
| 2 | Техническое задание: ТЗ №1 на изделие в целом + ТЗ №2 на адаптацию ПТК |
| 3 | Адаптация, комплектование и сборка ПТК в соответствии с ТЗ №2 |

Финальный прогон (комплексная проверка реализованной функциональности) подразумевается
в составе результата работ по умолчанию.

**Не включено в N2:** разработка КД, эксплуатационной документации (ИД), изготовление
металлоконструкций — планируются отдельным заказом (условие У.1 спецификации).

## 6. ЗАКАЗ N3 · ПТК HORIZON VM ДЛЯ ПАРКА WATE TECHNOLOGY

**Предмет:** реверс-инжиниринг группы аппаратов `Wate technology` и адаптация ПТК
для **6 моделей**. Состав работ по каждой модели — идентичный заказу N2
(анализ → ТЗ → адаптация/сборка ПТК + финальная проверка), итого 36 позиций.
Модели парка:

| № | Модель | Тип / канальность |
| :---: | :--- | :--- |
| 1 | WATE **G24P** | весовой, 24 канала (Smart Weighing Line Edge Warehouse) |
| 2 | WATE **C100 (slave)** | ящичный, 100 каналов (Smart Drawer Line-side Warehouse) |
| 3 | WATE **L8050/master** | гибридный (спираль/постамат) |
| 4 | WATE **L80/master** | спиральный |
| 5 | WATE **L50/master** | спиральный |
| 6 | WATE **C80P/master** | постаматный |

**Не включено в N3:** КД и изготовление металлоконструкций, монтаж парка (перспективный
N6), исполнительная/эксплуатационная документация (перспективный N7); G24P —
кандидат выделенного отдельного заказа. Аудит на заводе-изготовителе отменён
заказчиком — взамен технический митап (10–15 вопросов от исполнителя) и совместная
выездная приёмка оборудования.

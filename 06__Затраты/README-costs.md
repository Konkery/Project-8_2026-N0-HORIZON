## 4. КРАТКИЕ КОММЕНТАРИИ ПО ПУНКТАМ РЕЕСТРА

- **П. 2.1** — единственный документ затраты рамки на текущий момент; относится к
  юридически-организационному обеспечению сделки, на себестоимость заказов не
  разносится.
- **П. 2.2–2.3** — файлы содержат оценки трудозатрат внешних исполнителей;
  используется для подбора субподряда и проверки маржинальности КД-работ.
- **`02__Командировки`** — заранее зарезервирован под консалтинг выездной приёмки
  N3 (199 800,00 ₽ без НДС по позициям `3.x04.1` — в выручке, расходы — здесь).
- **Нумерация подкаталогов** — стандартная для ИРП группы: 01, 02, 04, 05, 06
  (категории 03 в структуре нет — это не потеря).
- **Конфиденциальность** — закупочные цены и условия субподрядов из затратных
  документов во внешние выпуски не выносятся.

## 5. ПОРЯДОК ВЕДЕНИЯ

1. Регистрируется любая затрата с указанием цели («для чего потрачено») и заказа/этапа.
2. Документ-основание — скан в `04__Сканы чеков\` или ссылка на файл в заказе.
3. Затраты, относящиеся к заказу, дублируются строкой в его реестре (первоисточник — там).
4. Статус: учтена → подтверждена документом → отнесена на себестоимость/закрыта.

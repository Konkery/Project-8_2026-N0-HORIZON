## 1. НАЗНАЧЕНИЕ РАЗДЕЛА И МЕСТО В ИЕРАРХИИ

Каталог `07__Логистика/` (`01__Габариты и вес/`, `02__Маркировка/`) — учёт всех
перемещений группы заказов: перевозчик, груз, отправитель и получатель, номер
отправки, доверенность, стоимость и страхование. Рамка держит **план операций по
портфелю** и габаритные данные как базу расчёта; отправки регистрируются в реестре
того заказа, чей груз перемещается.

## 5. КРАТКИЕ КОММЕНТАРИИ ПО ПУНКТАМ РЕЕСТРА

- **П. 2** — реестр не заполнен: контрактование заказов завершено, фактические
  перемещения ещё не начались.
- **П. 3.1–3.2** — передача исходных экземпляров оформляется актом по форме М15
  (см. `01__Документация\Акты приема-передачи\` соответствующего заказа).
- **П. 3.3** — по парку Wate транспортные расходы учитываются в схеме консалтинга
  выездной приёмки; перевозчик выбирается по коммерческому запросу.
- **Габариты** — для Knowhy N96/G80 и моделей Wate берутся из manufacturer ID
  (`03__Проект\01__ИД\` заказов); для КД N1 — по мере выпуска чертежей тары.
- **Страхование** — партии оборудования на площадке конечного заказчика
  страхуются до начала монтажа; условия — в договорах логистики (`04__Договор\`).

## 6. ПОРЯДОК ВЕДЕНИЯ

1. Строка заводится в день передачи груза перевозчику, закрывается по получении.
2. Указываются: перевозчик с реквизитами договора, отправитель/получатель,
   номер отправки, доверенность, стоимость перевозки и страховки.
3. Стоимость отправки переносится в реестр затрат соответствующего заказа.
4. Габаритно-массовые данные — версия с датой; при изменении КД — перевыпуск.

## 5. КРАТКИЕ КОММЕНТАРИИ ПО ПУНКТАМ РЕЕСТРА

- **N1 (п. 2)** — акцептованная редакция содержит опечатку модели в У.4
  (`Knowhy G80` вместо `N96`); урегулируется перепиской, выпуск новой
  редакции спецификации не требуется.
- **N2 (п. 2)** — единственный выпуск заказа, подписанный без расхождений;
  переэкспорт nosign 23.10.2026 — техническая актуализация файла.
- **N3 (п. 2, rev.01)** — правка У.2 расширяла состав результатов за границы
  объёма исполнителя; позиция: акт испытаний ПО всех уровней не выдаётся
  (АСУ ВУ разрабатывает иное юрлицо), результат — полнофункциональный прототип.
- **rev.02 v02 (п. 2)** — в файле сохранён срок У.11 до 22.10.2026 (наблюдение:
  при подтверждении договорённостей срок требует переноса).
- **В процентах vs сумма** — в выпусках ТКП указываются только абсолютные суммы;
  проценты авансов — внутренний инструмент планирования.
- **Поставщики (п. 4)** — закупочные цены, `SUPPLIER`, артикулы и наценки
  во внешние документы не выносятся.

## 6. ПОРЯДОК ВЕДЕНИЯ

1. Каждый выпуск/редакция ТКП — отдельная строка п. 2 с указанием, **что изменено
   и почему**; версии обозначаются `rev.XX vYY`.
2. Отказ стороны или отзыв выпуска отмечается статусом с датой, строка не удаляется.
3. Каждая сверка редакций — строка п. 3 со ссылкой на отчёты.
4. Переход выпусков из `00__draft\` на верхний уровень каталога заказа
   фиксируется обновлением пути в п. 2.
